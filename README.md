# nrlx

**NRL eXtended** — a Python toolkit for building, validating, and debugging seismic instrument responses.

`nrlx` is planned as a CLI and Python library around NRL v2, ObsPy, RESP, and StationXML workflows.

## Install

```bash
pip install nrlx

```

## Usage

```bash
nrlx version
nrlx doctor station.xml

```
